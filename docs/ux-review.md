# UX review: refinements ranked by impact

Reviewer: product design pass, 08 Nov 2026. Inputs: `docs/ui-brief.md` (authoritative), screenshots in `docs/ui-screens/`, selective reads of `apps/web/src`. Stale `shell-*` files and the firm `-390` files other than overview and approvals were skipped. No code was changed.

Four real days were used as test scripts:

- **Principal, Monday 09:30.** Asha opens Overview to see firm health and decide what to chase.
- **PM, Tuesday.** Vikram approves last week's time and fixes the Working drawings overrun on PRJ-01.
- **Finance, 30th of the month.** Farah prepares and submits a billing draft and chases INV-DEMO-0007.
- **Staff architect, on site.** Rohan logs 3 h of site time on a phone, one-handed, between meetings.

## 1. Summary: the five changes with the biggest effect

1. **Phone timesheet becomes a day view.** Below 768 px, show a `WeekStrip` with one day's lines, defaulting to today, instead of a 7-column grid that scrolls sideways and hides today's column (UX-01).
2. **Log time puts Recent and hours first.** Add one-tap Recent chips above the project search, keep Hours and Date visible while searching, and make the footer Cancel and Save only (UX-02).
3. **Approvals preview gets Return, a day breakdown and Undo.** The 1440 preview has only Approve and Delegate. Add Return with an inline reason, a Mon to Sun hours strip, and an Undo action on the toast (UX-03, UX-04).
4. **Every "needs attention" item ends in a verb.** Overview, project Needs attention and Phases rows should open the screen that fixes the problem, for example "Revise budget" prefilled for Working drawings +30 h (UX-05, UX-07).
5. **Forms inside sheets sit on solid surfaces, and the right units go into headers.** This removes the blurred colour behind sheet fields and the double-width "38.50  h" spacing. Both are brief rules the screens currently break (UX-09, UX-10).

## 4. Brief changes to consider

1. **Update WCAG 2.1 AA to 2.2 AA** in section 1 and section 13. Name SC 2.4.11 Focus Not Obscured (Minimum), SC 2.5.8 Target Size (Minimum, 24×24 CSS px) and SC 3.3.7 Redundant Entry. Redundant Entry backs the Recent chips in Log time.
2. **Glass in sheets.** Say explicitly: "Sheet header and footer are glass. A sheet body that contains form fields is `--surface`." This resolves the conflict between "sheets are glass" and "forms sit on solid surfaces" (UX-09).
3. **Mobile timesheet pattern.** Add to `TimesheetGrid`: "Below 768 px renders as day mode (WeekStrip plus line cards); the 7-column grid is desktop only" (UX-01).
4. **Priority is not a status.** Add to section 10: priority renders as text (High, Normal, Low), never as a status colour (UX-12).
5. **Reversible actions use Undo, not confirmation.** Add to the `Toast` row: approve, return, delegate and allocation moves show an Undo action for 5 s. Confirmation dialogs are reserved for irreversible actions (finalise invoice, submit to accounting).
6. **Units in prose.** Extend principle 4 so that, outside tables, the number is mono and the unit is sans, never a mono space before the unit (UX-10).
7. **Spelling.** State Indian English (utilisation, organisation, ageing) in section 2.3. The UI already uses "ageing", so "Utilization" is the odd one out.
8. **Charts.** Part-to-whole with one category goes in a `SegmentedBar`, not a ring. Add the rule "no donut for fewer than 2 non-zero segments" (UX-06).
9. **Every attention item names its fix.** Add to `AttentionList`: each item type maps to one verb and one destination route (UX-05).
